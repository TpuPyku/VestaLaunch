# VestaLaunch

Запуск программ для головного устройства (ГУ) MMC Lada Vesta на Windows CE 6 с экраном 800×480. Встаёт на кнопку
«Навигация» штатной оболочки: нажали кнопку — открылся список ваших программ (навигаторы, карты, плееры), нажали
плитку — программа запустилась поверх оболочки. Радио, музыка, телефон и настройки оболочки остаются прежними.
Программа бесплатная.

![Экран «Приложения»](VestaLaunch.jpg)

## Возможности

- **Кнопка «Программы»** вместо «Навигации» открывает VestaLaunch.
- **Свой список программ:** плитки по 8 на страницу, ярлыки правятся прямо на ГУ (своя клавиатура и выбор файлов).
- **Программа поверх оболочки;** после её закрытия на экран возвращается VestaLaunch.
- **Одна копия программы:** повторное нажатие на плитку выводит её окно вперёд.
- **Камера заднего хода** оболочки выходит поверх навигатора.
- **Диспетчер задач:** загрузка процессора и памяти, процессы и окна.
- **Своё оформление** в `Skin\skin.ini`.

## Установка

1. Скачайте архив `VestaLaunchInstall` из [Releases](../../releases) и распакуйте на SD-карту.
2. Запустите `LaunchInstall.exe` на ГУ (из проводника или кнопкой «Навигация»).
3. Нажмите **УСТАНОВИТЬ** и перезагрузите ГУ.

Установщик рассчитан на штатную оболочку прошивки 4120; незнакомую или защищённую прошивку он не меняет. Подробно — в
[руководстве пользователя](docs/manual.md#2-установка-обновление-удаление).

## Сборка

Visual Studio 2005 с поддержкой Smart Device и SDK Pocket PC 2003:

1. `native\build.bat` → `VestaLaunch\VestaLaunch.exe` (ARM) и `VestaLaunchPC.exe` (ПК, для проверки интерфейса).
2. `LaunchInstall\native\build.bat` → `LaunchInstall\LaunchInstall\LaunchInstall.exe`. В установщик упаковывается
   текущая сборка из `VestaLaunch\` (exe и `Skin`), поэтому его собирают после шага 1.

`VestaLaunchPC.exe /export` выгружает встроенную графику в `Skin\`: PNG и `skin.ini` по умолчанию.

Общие модули — подмодуль `core` ([VestaCore](https://github.com/TpuPyku/VestaCore)).
