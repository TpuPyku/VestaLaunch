# LaunchInstall — установщик VestaLaunch с патчем G3NavHMI и автооткатом

Один файл `LaunchInstall\LaunchInstall.exe` (Windows CE, ARM, ~165 КБ, импорт только COREDLL).
Внутри — VestaLaunch вместе с папкой `Skin`. Скин оболочки VESTA этот установщик **не** ставит:
полный комплект со скином — `Install\VestaInstall.exe`.

## Что делает «Установить»
1. Распаковывает VestaLaunch в `\SDMMC\VestaLaunch.new` и сверяет каждый файл со встроенным.
   `apps.txt` прежней установки переносится.
2. `G3NavHMI.exe`: патч AppLauncher `127.0.0.1` → `127.0.0.2` (один байт, у 4120 это смещение `0x30A244`).
   Делается, только если в exe ровно одно `127.0.0.1` и нет `127.0.0.2`. Если уже стоит `127.0.0.2`,
   exe не трогается. Любой другой расклад — незнакомая прошивка, установка отменяется.
   Перед патчем — копия `G3NavHMI.exe.vlaunch.bak` рядом и `\SDMMC\VestaLaunch_backup\G3NavHMI.exe`.
   После патча exe сравнивается с копией: должен отличаться ровно этот байт.
3. `Config\ExternNavi.cfg`: `\SDMMC\VestaLaunch\VestaLaunch.exe` первой строкой (остальные строки
   переносятся побайтно). Запись через временный файл, потом проверка.
4. Новая папка VestaLaunch встаёт на место; прежняя лежит как `VestaLaunch.old` до конца установки.
5. Если для патча закрывали оболочку — запускает её снова и 30 с следит, что она жива.

Каждый шаг пишется в журнал `\SDMMC\VestaLaunch_install.jrn` **до** выполнения. Любая ошибка записи
или проверки, а также оболочка, упавшая за 30 с, — откат всех сделанных шагов в обратном порядке и
запуск заводской оболочки. Если установку прервали (выключили ГУ), следующее «Установить» или
«Удалить» сначала откатывает её по журналу.

Отказ сразу, ничего не меняя: повреждён сам установщик (CRC встроенных файлов), нет `G3NavHMI.exe`,
незнакомая прошивка, мало места для копии exe, заряжено загрузочное обновление
(`\ResidentFlash\SwUpdate.flag`).

## «Удалить»
Убирает нашу строку из `ExternNavi.cfg` (файл становится побайтно прежним), возвращает заводской
`G3NavHMI.exe` из копии (только если патчил этот установщик), удаляет `\SDMMC\VestaLaunch`
(вместе с `apps.txt`).

## Использование
Положить `LaunchInstall.exe` на SD, запустить, нажать «Установить». Перед патчем установщик
спрашивает разрешения закрыть оболочку: без неё ГУ перезагружается примерно через 2 минуты,
поэтому она сразу запускается снова. Отчёт по шагам — на экране и в `LaunchInstall.log` рядом с exe.

Для скриптов: `LaunchInstall.exe ["<папка оболочки>"] status|install|uninstall` (без вопросов;
код выхода 0 = успех). Папка по умолчанию — `\ResidentFlash\navigation\app`.

## Сборка
`native\build.bat` (VS2005): упаковывает текущую сборку `VestaLaunch\VestaLaunch` (exe + `Skin`) в
`payload.bin` (`make_payload.py`), встраивает его и значок VestaLaunch ресурсами, собирает
`LaunchInstall.exe` (ARM) и `LaunchInstallPC.exe` (ПК). Сначала собрать VestaLaunch.

ПК-сборка для проверок: папка `SDMMC` берётся рядом с папкой оболочки (`<app>\..\SDMMC`), роль
оболочки играет программа из переменной `LI_SHELL` (наблюдение 3 с).
